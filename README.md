# OmaLux

A fast, keyboard-first raw developer for [Omarchy](https://omarchy.org).
Open a culled shoot, get each pick's exposure, colour, noise and lens
problems sorted with Lightroom's controls and keys, paste the settings
across similar frames, and hand them to
[Omapix](https://github.com/michaelrubi/omapix) as 16-bit TIFFs.

> OmaLux is an independent project. It is not made by or affiliated with
> Omarchy.

It's the second stage of one workflow: cull in
[Omacull](https://github.com/michaelrubi/omacull), develop in OmaLux,
retouch in Omapix, export.

**Status:** scoped, not built yet. [docs/DESIGN.md](docs/DESIGN.md) has
the design and [docs/ROADMAP.md](docs/ROADMAP.md) the plan.
